# World Narrative Factory

## Purpose

Create a world/narrative review for lived-in logic, harbor economy, social structure, and story hooks.

## Inputs

- District plan
- Building roles
- NPC/activity plan
- Interaction anchors
- Screenshots or true-blocker escalation context

## Procedure

1. Identify civic, market, tavern, harbor, service, and residential logic.
2. Check whether labor, class, commerce, and public life are visible.
3. Check whether story hooks are implied by place.
4. For Newport, verify harbor economy reads structurally.

## Required Output

```markdown
## World/Narrative Review
- Status:
- District Logic:
- Harbor Economy:
- Social Texture:
- Story Hooks:
- Council Authority Contribution:
```

## Fail Fast

Fail if the place reads as arbitrary buildings instead of a lived-in settlement.
