# UX / Player Experience Factory

## Purpose

Create a player-experience review for navigation readability, landmark orientation, screenshot framing, and player intent.

## Inputs

- Screenshots
- Camera/capture manifest
- Player spawn
- Route and interaction targets
- Known confusion risks

## Procedure

1. Check first-read landmarks.
2. Check route clarity.
3. Check door and interaction readability.
4. Check camera framing.
5. Identify player confusion points.

## Required Output

```markdown
## UX Review
- Visual Review Status: PASS / FAIL / BLOCKED
- Landmark Orientation:
- Navigation Clarity:
- Interaction Readability:
- Screenshot Framing:
- Council Authority Contribution:
```

## Fail Fast

Fail or require repair when a player cannot tell what is path, lot, prop, door, or landmark.
