# Game Design Factory

## Purpose

Create a gameplay-space review for movement, exploration rhythm, interaction density, and NPC usability.

## Inputs

- Phase brief
- Map/district plan
- Route targets
- Interaction anchors
- Screenshots or `NEEDS_HUMAN_REVIEW`

## Procedure

1. Identify the intended player loops.
2. Check whether each loop has purpose and landmarks.
3. Check whether interaction anchors appear every few seconds of movement.
4. Check if NPCs could use the space.
5. For Newport, reject asset-board layouts.

## Required Output

```markdown
## Game Designer Review
- Status:
- Movement Loops:
- Interaction Density:
- NPC/Player Usability:
- Fail Conditions Hit:
- Recommendation for Chris:
```

## Fail Fast

Fail if a town pass has buildings and props but no believable settlement circulation.
