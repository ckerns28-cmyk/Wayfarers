# Newport City Review Checklist

Use this checklist for any Newport city, district, layout, visual, or exploration pass.

## City Read

- [ ] Newport reads as a harbor city, not an asset board.
- [ ] The waterfront avenue is parallel to the harbor.
- [ ] Roads run uphill from harbor into town.
- [ ] A back street exists behind the first road.
- [ ] Districts are legible: harbor, market, tavern, civic, residential, service.
- [ ] The harbor economy is visible through docks, warehouses, cargo, work yards, and service routes.

## Visual Order

- [ ] The first, second, and third things a new player notices match the active phase goal.
- [ ] Tavern, counting house, commercial row, civic frontage, and harbor work zones are readable without relying on labels.
- [ ] Roads, alleys, and wharf paths do not visually run under building bodies.
- [ ] Building fronts align with believable lots, plazas, yards, docks, or streets.
- [ ] Ground transitions support route order instead of looking like disconnected editor patches.
- [ ] Screenshots do not contradict the written phase report.

## Walkability

- [ ] Harbor loop is readable.
- [ ] Market loop is readable.
- [ ] Civic/residential loop is readable.
- [ ] Alleys and service routes connect rather than dead-end randomly.
- [ ] Player and NPC routes are plausible.
- [ ] Water edges are controlled and not accidentally walkable.

## Interaction Rhythm

- [ ] Tavern/Inn entrance reads as a social anchor.
- [ ] Civic entrance reads as public/civic space.
- [ ] Shops and market stalls read as commerce.
- [ ] Dock worker/cargo interactions read as harbor work.
- [ ] Something potentially interactable appears every 8-12 seconds of walking.

## Fail Conditions

- [ ] Buildings are sitting on old/prototype ground art.
- [ ] Props are hiding layout problems.
- [ ] The scene cannot plausibly support NPC village behavior.
- [ ] Taverns, civic buildings, shops, or harbor buildings look randomly ordered.
- [ ] A runtime screenshot shows route/building/ground confusion that the report claims is solved.
- [ ] The pass does not approach the phase's Newport 8.5+/10 bar.
