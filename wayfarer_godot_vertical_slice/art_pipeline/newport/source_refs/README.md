# Newport Source References

G-4.17 uses only in-repository, project-owned art as style references:

- `assets/buildings/*.png`
- `assets/sprites/buildings/isolated/*.png`
- `source_refs/hearthvale_props_atlas_v1_transparent.png`, copied from
  `wayfarer_v7_github_ready/worker/assets/wayfarer/props/`

The generated hero street atlas is project-owned bitmap art created from
measured building material targets, source crops from the Newport building
sprites, and project-owned prior prop sprites. No external scraped or
unlicensed art was used.
