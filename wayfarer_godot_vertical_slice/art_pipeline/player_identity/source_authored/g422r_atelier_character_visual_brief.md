# G-4.22R Atelier Character Visual Brief

The deterministic scratch character pack attempted during G-4.22R was rejected as below the active Newport atelier bar. This replacement uses a painterly AI-assisted green-origin source sheet, local chroma-key extraction, and manifest-backed runtime atlases.

Required normal-play rule: the player and visible NPCs must never fall back to hand-drawn primitive shapes, beige/tan humanoids, or debug marker silhouettes. If a character cannot be sourced through this or a stronger approved pipeline, it must be hidden from normal screenshots.
