Build label: Godot Vertical Slice route: /godot/ status: export pending

This route is reserved for the Godot 4.x vertical slice preview. The route is wired into the existing Cloudflare Worker, but the compiled web export has not been uploaded yet, so this placeholder is being served instead of the real Godot canvas.

When the export is in place this page is replaced by the real Godot HTML shell, which will load the .wasm / .pck files from the same /godot/ path. The JavaScript site at / is unaffected by this preview route.

To finish the deploy

cd wayfarer_godot_vertical_slice
bash tools/export_web.sh
git add wayfarer_v7_github_ready/worker/assets/godot wayfarer_godot_vertical_slice/export/web
git commit -m "Deploy Godot vertical slice web export"
git push

tools/export_web.sh runs godot --export-release "Web" against export_presets.cfg, lands the build in wayfarer_godot_vertical_slice/export/web/, and copies the same files into wayfarer_v7_github_ready/worker/assets/godot/ so this Worker can serve them at /godot/ on the next deploy.

Confirming the JS site is untouched

Visit / to confirm the existing JavaScript build (current production tag Build Phase 35.13R) is serving normally. The Godot route is additive only.
